# Solpient Money V0.2

V0.2 converts the visual prototype into a functional local-first application.

## Included

- Route-based navigation
- Accounts consolidation view
- Searchable and filterable transactions
- Interactive net-worth, cash-flow, and portfolio-performance charts
- Portfolio holdings and allocation
- Individual holding detail pages
- Deterministic portfolio intelligence
- Retirement, goals, debt, insights, and Research integration surfaces

All financial values in V0.2 are synthetic demo data. No live financial account credentials or personal financial exports are stored in this repository.
